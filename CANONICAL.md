# WHP Sentinel Canonical Machine

This repository is the integration layer for the current Wheeler Hubbell Publishing decision-integrity system.

The live canonical machine is exactly this:

- Wheeler Hubbell Publishing
- Decision Integrity Protocol
- Unilateral Integrity
- Standing Mark Service
- Standing Gate
- Standing Mark
- Standing Assessment

## Rule

A leaf cannot define the whole.

The system is defined by the canonical root, not by a single helper file, demo script, or historical note.

If a file does not directly serve the live canonical machine, it belongs under `archive/` and must not be mistaken for the current system.

## Scope

This repo's live scope is limited to:

- the sentinel evaluation flow
- the decision-integrity client pattern
- live and dry-run evaluation paths
- integration with the Standing Mark Service and Standing Gate

## Archive rule

All historical, exploratory, or non-authoritative material belongs in `archive/`.

Anything not directly tied to the active protocol, runtime, or enforcement path is not the canonical system.

## Enforcement

No assistant, workflow, or contributor should treat a single template file or discovery artifact as the whole system.

The live canonical machine above is the only authoritative definition of the current system.
